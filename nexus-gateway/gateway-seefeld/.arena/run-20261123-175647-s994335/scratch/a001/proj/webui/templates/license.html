Come funziona il sistema di licenza
La chiave è legata al numero seriale hardware di questo Raspberry Pi — non funziona su nessun altro dispositivo. Ogni anno (o alla scadenza) il rivenditore genera una nuova chiave di rinnovo usando lo stesso seriale. Il gateway continua a funzionare anche dopo la scadenza ma non riceve più aggiornamenti software.
