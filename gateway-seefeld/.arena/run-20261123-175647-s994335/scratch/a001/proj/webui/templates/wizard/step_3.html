Suggerimento: chiedi all'IT di configurare il router perché al Pi venga sempre assegnato lo stesso IP (DHCP reservation). Se il Pi cambia IP dopo un reboot, gli analizzatori non lo trovano più.

🔍 Come trovo l'IP del gestionale?

  1. Vai sul PC del medico dove è installato Tomedo/Vitomed/curaMED
  2. Apri il prompt: Win+R → cmd
  3. Digita ipconfig
  4. Copia "Indirizzo IPv4" (di solito 192.168.x.x)

La porta standard MLLP è 2575. Se il gestionale usa una porta diversa, la imposteremo al passo 5.

⚠️ Se il test fallisce

  • Il gestionale è acceso?
  • C'è un firewall che blocca la porta 2575?
  • L'IP è corretto?

Puoi comunque procedere e sistemarlo dopo — questo test è solo informativo.
