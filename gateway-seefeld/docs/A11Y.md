# Accessibility

Target: **WCAG 2.1 Level AA** for every screen the operator uses.

## Enforced by CI

- `axe-core` runs against every Playwright E2E test — a violation
  breaks the build.
- Contrast ratios checked against the vendor palette
  (`webui/static/style.css` :root tokens).
- All interactive elements reachable by keyboard — Playwright drives
  each button, link, and form field with `page.keyboard.press("Tab")`
  and asserts focus reaches it.

## Design guarantees

- Every icon has a text alternative (either visible label or
  `aria-label`).
- Every form field has a `<label for="id">`.
- Every table has `<th scope>`, and complex tables carry a
  `<caption>`.
- Every alert is `role="alert"` or `role="status"` as appropriate.
- Modal dialogs trap focus and restore it on close.
- The Web UI works without JavaScript for read-only views.

## Screen reader tested

Manual acceptance testing on:
- NVDA + Firefox (Windows)
- VoiceOver + Safari (macOS)
- Orca + Firefox (Linux)

## Font & color

- Body text at 16 px minimum; UI chrome at 14 px minimum.
- No color-only signals — every red/green/yellow status is duplicated
  by an icon and a text label.

## Reporting an accessibility issue

Email `accessibility@jerumednexus.example` — treated as a P1 bug and
fixed in the next patch release.
