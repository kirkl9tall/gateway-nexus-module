Passo 1 — Come è collegato al Raspberry Pi?
🔌
USB (RS-232 seriale)
Cavo seriale + adattatore USB → porta USB del Pi
🔗
TCP (rete cablata)
Il device invia via Ethernet al Raspberry Pi
Passo 2 — Parametri di connessione
Verifica con: ls /dev/ttyUSB* — o usa il symlink /dev/jerumednexus/*
0.0.0.0 = accetta connessioni da qualsiasi IP
Configurare la stessa porta sul device
Passo 3 — Identità e protocollo
Es. sysmex-xn550, cobas-c111. Solo [a-z 0-9 _ -], 2-40 caratteri.
Se il protocollo non è in lista, scegli "Custom" e inserisci l'ID adapter — richiede un plugin Python.
