💾 Cosa fa questo passo

Configuro un backup automatico giornaliero (di notte, ora 02:15) di:

  • Configurazione del gateway
  • Cronologia dispatch (chi ha mandato cosa, quando)
  • Audit log
  • Dead-letter queue (messaggi non arrivati)
  • Chiavi di cifratura

Se il Pi si rompe, con un backup recente ripristini tutto su un Pi nuovo in 2 ore (vedi Disaster Recovery runbook).

Regola d'oro medica: il backup non testato non esiste. Il gateway include uno script verify_backup.sh che ogni mese ripristina l'ultimo backup in una cartella temporanea e verifica l'integrità. Chiedi all'IT di schedulare quello script nel cron mensile.

🔐 Cifratura GPG

Se il NAS è condiviso con altri servizi della clinica o backup off-site, cifra i backup. In pratica:

  1. Chi installa deve avere una chiave GPG personale
  2. Il gateway cifra ogni backup con quella chiave pubblica
  3. Solo quella persona (con la chiave privata) può decifrare
  4. Il vendor NON può leggere il backup — è sicuro per GDPR/nDSG

Se non sai cos'è GPG, chiedi all'IT o al DPO. Per praxis piccole, il rischio è basso (NAS interno) — puoi anche saltare per adesso.

🌐 Backup off-site (opzionale)

Per la massima protezione (ransomware-proof): un secondo backup su Backblaze B2 o Cubbit (fornitori EU) con object-lock. Costa ~5 EUR/mese. Da configurare dopo, dal menu Backup.
