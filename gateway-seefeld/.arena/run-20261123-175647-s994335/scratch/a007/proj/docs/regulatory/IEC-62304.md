# IEC 62304 software lifecycle checklist

Fill in during your QMS review before each release.

## 1. Software safety classification (IEC 62304 §4.3)

- [ ] Class A -- no injury / damage to health possible
- [ ] Class B -- non-serious injury possible
- [ ] Class C -- serious injury or death possible

**JerumedNexus Gateway (default position): Class A.**
Justification: the gateway performs no clinical decision. A malformed
message would be rejected by the LIS at the ACK step, not misinterpreted.
The flag mapping (UP/DOWN -> H/L) is data pass-through, not clinical logic.

Any customer deployment that changes this assumption (e.g. layer that fires
alerts based on results) must be reassessed by the customer.
