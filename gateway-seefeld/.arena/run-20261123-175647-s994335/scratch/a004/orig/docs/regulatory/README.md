# Regulatory documentation templates

**IMPORTANT: these are templates, not legal documents.** They cover the
paperwork you must produce to sell the JerumedNexus Gateway as a regulated
laboratory integration product in Switzerland / EU. Fill each one in with
a qualified regulatory consultant and your Quality Manager.

Nothing in this repository constitutes legal, medical or regulatory advice.

## When you need which document

| Scenario | Documents |
|----------|-----------|
| Selling to a private practice in Switzerland | `DPA-TEMPLATE.md` |
| Same, but the gateway performs *any* transformation (flag mapping, unit conversion, LOINC recoding) | `DPA-TEMPLATE.md` + `RISK-ANALYSIS.md` + `IVDR-CHECKLIST.md` |
| Selling to a hospital / EU customer | Everything below |
| Signing a QMS (ISO 13485) | Everything below + external audit |

## Contents

- [`DPA-TEMPLATE.md`](DPA-TEMPLATE.md) -- Data processing agreement (nDSG / GDPR Art. 28) template for practices deploying the gateway.
- [`RISK-ANALYSIS.md`](RISK-ANALYSIS.md) -- ISO 14971 risk management file template.
- [`IEC-62304.md`](IEC-62304.md) -- Software lifecycle process checklist (Class A/B/C).
- [`IVDR-CHECKLIST.md`](IVDR-CHECKLIST.md) -- IVDR Class A conformity-assessment checklist.

## Recommended consultants (Swiss / DACH)

The maintainers do not endorse specific firms. Ask your existing legal /
notified body contact, or search for:

- ISO 13485 QMS consultants
- IVDR notified bodies (SQS, TÜV Süd, SGS)
- FDPIC-registered DPO providers
