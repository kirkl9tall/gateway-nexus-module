🚀 Cosa succede al click "Salva e avvia"

  1. Scrivo config/gateway.yaml con tutte le tue scelte
  2. Attivo il profilo del primo analizzatore
  3. Il gateway si accorge del cambio config e si riavvia da solo
  4. Vieni redirezionato alla Dashboard

✅ Come verificare che funziona

  1. Sulla Dashboard, la tessera del primo analizzatore deve diventare verde entro 10-30 secondi (indica che aspetta la connessione)
  2. Chiedi al tecnico di puntare l'analizzatore all'IP {{ data.pi_ip }} porta {{ data.first_device_port }}
  3. Fai un test sul device
  4. Il risultato appare nella sezione Risultati di oggi
  5. Controlla che appaia anche nel gestionale del medico
Se qualcosa non funziona:
  1. Menu Log di sistema — cerca errori in rosso
  2. Menu Trace protocollo — vedi i byte grezzi ricevuti dal device
  3. Menu Dead-letter — se ci sono messaggi bloccati con l'errore
  4. Menu Frame Inspector — controlla trasformazioni sui valori
